## 使用方式

### 在 `blogref` 工具中

```bash
# 列出所有分類代碼對照
bash /opt/data/scripts/blogref categories

# 依分類名稱搜尋（自動對應代碼）
bash /opt/data/scripts/blogref attractions --category 自然風景類
bash /opt/data/scripts/blogref restaurants --cuisine 牛肉麵
bash /opt/data/scripts/blogref hotels --type 民宿
bash /opt/data/scripts/blogref events --type 節慶活動
```

### 在 Python 查詢中

```python
from blogger_ref import ATTRACTION_CLASSES, CUISINE_CLASSES, HOTEL_CLASSES, EVENT_CLASSES

# 代碼 → 中文
print(ATTRACTION_CLASSES[11])  # → '自然風景類'
print(CUISINE_CLASSES[113])    # → '牛肉麵'

# 中文 → 代碼（反向查詢需自己倒轉 dict）
code_map = {v: k for k, v in ATTRACTION_CLASSES.items()}
print(code_map['溫泉類'])      # → 10
```

### 在 SQL 查詢中

```sql
-- 旅宿依星等排序
SELECT name, hotel_stars FROM taiwan_hotels WHERE city = '花蓮縣' ORDER BY hotel_stars DESC;

-- 活動篩選進行中
SELECT name FROM taiwan_events WHERE end_datetime >= datetime('now') ORDER BY start_datetime;

-- 景點依分類代碼模糊搜尋（代碼 11 = 自然風景類）
SELECT name FROM taiwan_attractions WHERE category_codes LIKE '%11%';
```
