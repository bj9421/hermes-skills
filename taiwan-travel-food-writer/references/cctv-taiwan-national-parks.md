# 台灣國家（自然）公園 YouTube 即時影像

> 研究來源：交通部觀光署 `sNo=0043305` 頁面 + anysearch 搜尋 + livecam.tw 多輪驗證（2026-07-15 批次）
> 涵蓋範圍：內政部國家公園署轄下 10 處國家(自然)公園
> 目標平台：Blogger（17uu.tw）— HTML 嵌入

---

## 一、背景說明

不同於交通部觀光署的 13 處國家風景區，國家(自然)公園由內政部國家公園署管轄。即時影像來源更分散：
- 部分公園有自己的 YouTube 頻道（如雪霸、墾丁、陽明山）
- 部分依賴地方縣市政府 CCTV
- 部分（玉山）使用自有串流系統，無公開 YouTube 直播
- 保護區/管制區（東沙環礁、南方四島）完全無公開影像

## 二、驗證方法

三重交叉驗證流程：

```
anysearch 搜尋 "公園名稱 + 即時影像 + youtube + live"
  ↓ 取得疑似 URL
YouTube oembed API 驗證標題與類型
  ↓ 確認為有效影片
livecam.tw / 官方網站 交叉比對
  ↓ 確認為即時串流而非一般影片
寫入對照表
```

**oembed 驗證指令：**
```bash
curl -s "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=VIDEO_ID&format=json" \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('title','?'))"
```

**有效回傳** = 有 title 且含「即時影像」「Live」「直播」關鍵字
**無效回傳** = oembed 回 404 / JSONDecodeError / 回傳影片類型

## 五、已知陷阱

1. **玉山、東沙、南方四島無 YouTube** — 這三處目前沒有公開 YouTube 即時串流。玉山可用 livecam.tw 替代，東沙/南方四島無替代方案。
2. **oembed 非即時驗證** — oembed 只回傳影片 metadata，不保證串流仍在進行中。若連結失效，搜尋「公園名稱 + 即時影像 + 2026」更新。
3. **墾丁多來源** — 墾丁的即時影像來自屏東縣政府 CCTV 整合平台（非國家公園自營），ID 可能隨縣府合約變動。
